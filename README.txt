NIHAR MATCHPOINT — TEMPORARY VERSION

Upload these four website files to the root of your GitHub repository:
index.html, styles.css, app.js, config.js

Features:
- Singles and doubles matches
- Custom points and best-of formats
- Score editing with a local PIN
- Match list saved in browser storage
- Shareable scoreboard snapshot links
- No Firebase or billing

Limitations:
Matches stay on the browser/device where created. Shared links show a snapshot and do not sync later changes. This is not live multi-device scoring. Clearing browser data may remove saved matches.

To publish:
1. Open your GitHub repository.
2. Upload/replace the four files in the repository root.
3. Commit changes to the main branch.
4. Wait for GitHub Pages to rebuild.
